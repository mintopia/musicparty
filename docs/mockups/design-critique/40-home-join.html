Home, join and login

Entry screens: where a guest or host lands, how they enter a party code, and how a link from the TV or a friend gets them into the party after login. Party codes are four letters, the join URL is /parties/KXQB. Tickets #416, #417, #422; user feedback U6.

Login Unchanged

The photo and one Discord button, exactly as built today.

Home for a member Changed

Home was an empty column with a profile card. It now lists the member's parties with the same playback words as the Dashboard, and gives the code entry the front seat.

  • Round 3 (all pages): page head 40/800 and card titles 650 for a clear type step; empty states use the record-sleeve icon in the colours of the cover now playing.
  • Round 3: Home’s head sits on the player band’s stage, tinted by the cover playing at your live party; each party shows its state as a coloured pill (Playing with moving bars, Paused amber, Player stale red, Nothing playing grey).
  • Only the Playing bars move; the stage art would crossfade (600ms) if the live party changes track.
  • Your parties: name, live state (Playing, Paused, Nothing playing, Player stale), role badge and code per row. Reason: Home showed nothing but a profile card; the profile has its own page (#417).
  • Playback wording matches the Dashboard (#418). Managers open the Dashboard, guests open the Queue.
  • Enter party code: four letters, uppercased as typed. One filled button per screen (Join); Create party is outlined. U6.
  • Profile card dropped from Home; Profile is in the sidebar.

Home states New

A new member with no parties, and code entry rejecting digits with a plain message.

  • Code fields accept exactly four letters and show "Party codes are four letters, no digits." for digits. Wrong length is covered on the party-not-found page (41). U6.

Home when logged out Changed

Today the anonymous Home redirects straight to Login. It now offers the code field first, so a guest with a code from the TV can start without knowing where to go.

  • Entering a code goes to /parties/KXQB, which then asks for login (join flow below). U6.
  • GuestLayout and the Discord button are unchanged.

/parties list Changed

/parties currently crashes with a 500 for a logged-in member (capture: BadMethodCallException, PartyController::index does not exist). It shows the same list as Home.

  • Same list and code field as Home with the breadcrumb Home / Parties. #416 (500 on /parties).

Join from a link while logged out New

A link or QR to /parties/KXQB shows what the guest is joining, then login, then (first time only) a nickname, then lands in the party Queue.

  • The party card shows name, host, guests online and what is playing, so the guest knows the link is right before logging in. U6.
  • Three-step strip (Login, Nickname, In the party) reuses the Create Party steps. Nickname is skipped for returning members.
  • After login the guest returns to the party, not to Home. Open question: should a banned user see this page? Proposal: show the 403 page (41).
