Type and breadcrumbs

#425 · A steeper type scale, headings that never skip a level, breadcrumbs that always show separators and shorten on phone, and a skip link as the first Tab stop. Values are the ones in DIRECTION.md and assets/mockup.css.

Type scale

Every role at its real size. The spec column gives size / line height · weight · tracking; usage says where it applies.

  • Ratio rises from 1.14 to about 1.25, so h1, h2 and h3 are told apart at a glance. Today h1 and h4 differ by 4px.
  • Display (40px, 28px on phone) is for the stage band and status headline, not for page titles: the h1 stays 32px.
  • Small is 13px and used for hints and meta; nothing goes below it. Table cells stay 14px so dense tables fit.
  • The TV page keeps its own scale (88/40/52px at 1080p) and is not part of this table.

Heading levels on party Settings

A real page with the heading level tagged on each heading. Settings today jumps from h1 to h3; every card title is now an h2.

  • Level badges (purple h1, teal h2, orange h3) are annotation only and not part of the UI.
  • Card titles are h2 with .mp-card-head sizing them 19px; h3 sub-groups render at h4 size. Visual size and level are independent.
  • Setting hints are 13px, sit directly under their control, and keep the same 16px gutter as the card on phone, clear of the screen edge.
  • Copy follows #417: “Party is running” and “Fallback Playlist”.

Breadcrumbs

One shared breadcrumb component with chevron separators drawn by CSS, so the markup is just a list. The current page is plain text with aria-current="page".

  • Separators are CSS chevrons on li + li::before, hidden from assistive tech, so Settings can no longer render without them.
  • Phone keeps the last two levels and a “…” button that reveals the rest; non-current links cap at 14ch.
  • Links are 13px secondary colour; hover underlines; the last item is 600 weight in body colour.

Skip link

First element in the body, hidden until focused. Shown here in its focused state over the sidebar and header.

  • Appears top-left on focus with a primary fill, white text and a double ring (white inside, primary outside) so it reads on both the dark nav and light header.
  • Enter moves focus to #main; on every page main carries that id.
  • z-index is 2000, above Tabler's vertical navbar (1030); the current .mp-skip z-index of 1000 would hide it behind the sidebar, so the build must raise it.
  • Hidden state is translated off-screen, not display:none, so it stays focusable.
