Create party

Round 2 (#424; U6). Replaces the single long form (Create.vue, PartyForm.vue) with three steps that reuse Settings rows and labels.

Steps 1 to 3 Changed

One long form becomes three short steps: Name, Music, Defaults. Only the name is required, and "Create with defaults" is available from the first step. The rows are the Settings page's SettingRow with the same labels.

  • Round 3 (all pages): page head 40/800 and card titles 650 for a clear type step; empty states use the record-sleeve icon in the colours of the cover now playing.
  • Three steps (`ol.mp-steps`): Name, Music, Defaults. Reason: #424, one 20-field form was the main complaint in critique A-C.
  • Only the name is required. "Create with defaults" (outline, so Next stays the only filled button) is in the footer of steps 1 and 2. Defaults are the ones Settings shows.
  • Step 1 error says what to do: "Enter a name for your party." The field is marked invalid and keeps focus.
  • Step 2: Fallback Playlist is the same picker as Settings > Playback (cover, name, track count, search, "Use a playlist link or ID"). "Backup Playlist" is gone everywhere (decision 5). Play on replaces "Playback device".
  • Step 3: labels match Settings ("Hold Flagged Requests for approval", "Show join QR code"). Wording like "Process the queue and requests" and "Treat the queue as a raffle" is dropped; Party is running and Raffle mode stay in Settings, not here.
  • Advanced options (Ask Spotify what's playing, Always play on, Context playlist) are not in the wizard; they stay in Settings > Playback.
  • Open question: should country and timezone be detected from the browser? Mocked as pre-filled, editable.

Done New

After creating, the host gets the party code, the join link and a QR, with the two things they do next: open the Dashboard and open the TV.

  • Round 3: the done screen is the success moment: the code at display size on the player band’s stage, with a check. The stage uses the album-art wash until the party has a cover.
  • The check draws once (400ms, ease-out) when the screen appears; nothing else moves. Off under reduced motion.
  • Code is four letters, no digits (decision 4): `KXQB`. Join URL is `/parties/KXQB` (decision 4, #422/#424).
  • One filled button: Open Dashboard. Open TV is outline; Party settings is a link.
  • The QR is a placeholder, not scannable. The TV page is unchanged (U2); it already shows code and QR.
  • The sidebar now lists the new party; no player band yet because nothing is playing.

Phone Changed

Each step on a phone: steps collapse to the current step label, rows stack, and the footer buttons wrap to full-width targets.

  • The picker menu is full width on the phone and options are 52px tall.
  • On the done screen the QR sits under the code so it can be scanned from another phone.
  • Back stays a quiet link at the left; Next is the right-hand filled button.
