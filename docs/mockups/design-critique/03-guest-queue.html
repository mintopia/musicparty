Guest queue

Issue #420. Guest Queue on the shared vote control, with You tags and Fallback Playlist credit.

Queue, guest view (up and down voting)

The guest sees the same vote control as the now-playing strip. Their own Requests carry a You tag and a faint tint; Fallback Playlist tracks are credited to the party.

  • Vote states in the list: Sandstorm neutral (8), Dancing Queen voted up (5, green), Take On Me voted down (-2, red), Blue (Da Ba Dee) voted up on own Request.
  • Vote buttons are 40px on desktop and 44×44 on phone/touch, grouped in one pill so the score sits between the arrows. The visual size matches the strip.
  • "You" is a filled tag beside the title, so own Requests are identifiable without colour; the row tint is secondary. Own Requests drop the "Requested by" line.
  • Fallback Playlist rows say "From the party's Fallback Playlist" on desktop and the short "Fallback Playlist" on phone, with the confetti icon. Never "Fallback Track".
  • The sidebar is Tabler default; the stage band repeats the now-playing strip so the party stays visible while voting.

Queue, like mode

Parties that disable downvoting show a single heart and a score (VoteControl's non-downvote branch). Same pill, same 40/44px targets.

  • Liked state fills the heart in pink-red (`.is-like`), not green: it is a different signal from an upvote.
  • Scores never go below 0 in like mode, so the Take On Me row shows 0 and a neutral heart.
