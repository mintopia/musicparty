Review decisions

Decisions from the mockup review are recorded here.

  • Round 1 rejected: it did not build on the current app or the approved designs. Round 2 starts from the built pages.
  • Dashboard keeps the control room with the device picker and the health grid (Player, Device, Last update, Spotify link, Polling) always visible; no Diagnostics fold.
  • TV page and guest player band are final; shown unchanged.
  • Search page and the approved results layout (option A) stay.
  • Join URL is /parties/KXQB; party codes are four letters, no digits.
  • Words follow GLOSSARY.md: Request, Queue, Fallback Playlist, Sent to Player, Flagged Request, Moderator. “Sent to Player” replaces the built “Sent to Spotify” on the Dashboard too.
  • Moderator is a new party role between Owner and VIP (no Settings, no role changes, cannot start playback on the owner’s Spotify).
  • Table pages use one search field with typed filters and matching chips; no filter sidebars.
  • Dark mode per user is out of scope for #414; dark frames show the app’s existing dark mode only.
  • Sidebar is identical per role on every page: guest (Queue, Search), moderator (no Settings), owner (plus Create Party), site admin (plus Admin).
