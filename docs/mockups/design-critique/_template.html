Mockup template

Copy this file to start a page. The shell is the app's real AppLayout markup. Each screen is a <figure data-frame> with an id; its markup goes in a <template>, which assets/mockup.js renders in an iframe at the device's real width with app.css, components.css and mockup.css. Add data-theme="dark" for the app's dark mode.
