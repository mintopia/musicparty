Web Player Changed

Today the Web Player is a plain card with a status word and three buttons. It is the speaker for the party, so it now looks like the rest of the Player family (blurred-art backdrop, large art, title, artist, progress), adds real transport with keyboard hints, and shows the Player's own status where people can see it: the registered device, whether it reports to Music Party, and how long ago it last did. Failures say what is wrong and show the fix as the main button.

  • #423: blurred-art backdrop, art, title, artist, album and progress come from the TV and band language; transport is Previous, Play or Pause (largest), Next, as icon buttons with names for assistive tech.
  • Keyboard: Space, N and P are shown under the transport (hidden on phones). New behaviour: they need wiring in WebPlayer.vue.
  • Player status card (Device, Reporting, Last update, Spotify link) uses the same words as the Dashboard health grid, so "Reporting to Music Party" here and "Player" there agree (#418). Last update is in words ("2 seconds ago"), never raw minutes.
  • Not connected: Premium needed and Log in again each name the cause and put the fix first ("Open Spotify account", "Log in with Spotify"). The status card shows the same cause in red.
  • Taken over: today a yellow alert with no way back. Now it names the other player and offers "Use this tab instead" (new action; the claim protocol already supports a newer claim winning).
  • Leaving: the "closing this tab stops playback" warning is visible on the page, not only in the browser confirm.
  • Across the room: at 1920x1080 art, title and the status pill scale up like the TV page, so the speaker laptop can be read from the sofa. Dark mode changes only the card below the hero; the hero is always dark like the band.
