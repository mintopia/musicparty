Design critique mockups

Error pages and joining from the TV

Ticket #422. Branded 404, 500 and "Party not found" inside the app layout, each with a way home or back into a party, plus the TV page showing how guests join. Guests arrive by typing the code off the TV, so recovery from a typo is the main job.

404: page not found

The stage band fills the content area, so an error still feels like the party. The code field is here as well because a mistyped URL is the common cause.

  • Uses the normal shell: sidebar, header, breadcrumbs. "Go to Home" is the primary action.
  • "Error 404" is the only technical detail. The title says what happened in plain words.

500: something went wrong

No stack trace, exception, request ID or file path. Reassures that data is safe, then offers retry and home.

  • Warmer red tint instead of purple signals a fault, without alarm colours on text.
  • "Try again" is the primary action here, "Go to Home" secondary. Both are real links: 44px minimum tap size.
  • Production never shows exception detail; this page is the same in local and production for guests.

Party not found, with Enter party code

Shown when a party URL or code doesn't match a party. The field takes the guest straight to the party.

  • The field reuses .mp-code-input: uppercase, large, 4 characters, letter-spaced for reading off a TV.
  • When arriving from a typed code the field is prefilled with what they typed so the typo is visible. Error text names the code and tells them to check it.
  • Hint "Q and O look alike" appears with the error. No "did you mean" suggestion: that would reveal which parties exist.
  • Submit goes to the party page for that code; if it still doesn't exist, the same page returns.

TV page: join URL and QR code

Based on the real TV page: party name top left, join block top right, now playing below. Adds the join URL, enlarges the code and QR, and puts the three behind a panel so they hold up on a projector.

  • New: join URL under "Scan, or go to", then "and enter" with the code at 68px (was 52px). QR is 184px (was 152px) with a 6px quiet zone in white.
  • The join block has its own dark translucent panel so contrast does not depend on album art.
  • Nothing-playing state: URL at 60px, code at 128px and QR at 380px. First guest's job is joining, so it is the biggest thing on screen.
  • QR is on by default. Switched off, the panel keeps URL and code and the label reads "Go to".
