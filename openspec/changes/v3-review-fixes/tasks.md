# Tasks

Each checkbox is roughly one PR, done in its own worktree off `feature/v3-rewrite`. Each task lands its own Pest or Vitest tests at one of the seams in design.md ("Test seams"), and must pass PHPStan level 8, Pint and Rector. Tests run on in-memory SQLite with no other service (ADR-0024). While working, run only the affected tests; run the full suite before merging. Flaky tests block the merge. Any change to an `/api` route, an API Resource, a channel or a broadcast updates the OpenAPI or AsyncAPI document in the same PR. `[id]` is the finding id from the 2026-10-10 v3 review. Group dependencies are in design.md under "Task group ordering".
