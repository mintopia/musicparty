# Tasks

Each checkbox is roughly one PR, done in its own worktree off `feature/v3-rewrite`. Each task lands its own Pest or Vitest tests, using the Fake Music Provider, the Fake Player, `Http::fake` and `Queue::fake` wherever possible, and must pass PHPStan level 8, Pint and Rector. While working, run only the affected tests. Run the full suite before merging. Flaky tests block the merge. Any change to an `/api` route or a broadcast updates `openapi/openapi.json` (`php artisan openapi:generate`) or `asyncapi/asyncapi.json` in the same PR. `[#n]` is the audit finding number. Group dependencies are in design.md under "Task group ordering".
